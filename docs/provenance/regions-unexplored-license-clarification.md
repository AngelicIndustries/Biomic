# Regions Unexplored license clarification

The source selected for Biomic is
[`ApolloUnknowndev/RegionsUnexplored`](https://github.com/ApolloUnknowndev/RegionsUnexplored) at
commit `f5dfe4eea916cb7ccb4990faebc952459dad5f8b`.

At that revision, the root `LICENSE` is the MIT License with `Copyright (c) 2026 Apollo`. The README
still contains older all-rights-reserved wording. Jack asked the Regions Unexplored project Discord
which statement controls. On 2026-08-16, project maintainer EternalHell replied that the `LICENSE`
file is the most recent statement and confirmed: "so MIT it is".

The supplied Discord screenshot is a 1305-by-1477 PNG with SHA-256:

`f043cec1ba7f6a67aa599dfc64490afe1cc2284937b3b29316861c427ef26fc7`

The repository license remains the operative permission. The clarification is supporting evidence
for the README/LICENSE mismatch, not a substitute for preserving the MIT notice. Before updating
the RU pin, recheck the root license and this mismatch rather than assuming permission carries to a
later revision.
